<!-- A BASIC CLI APPLICATION THAT PERFORMS THESE FUNCTIONS -->

# ADD CONTACT

    Allows usert to add a contact to their phonebook, which includes name, phone number, email and date created.

# EDIT CONTACT
    Allows user to edit any section of their contact.

# DELETE CONTACT
    Allows user to delete specific contact.

# SEARCH CONTACT
    Allows user to search contact by name, phone number, email or timestamp.

# VIEW CONTACTS
    Allows use to view all contacts.
